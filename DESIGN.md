# Stitch Design System — Asan Office

## Principles
- **AI-Native**: Interfaces designed to be easily manipulated by agents and users.
- **Vibe Design**: High-fidelity, clean, and professional "Office" aesthetic.
- **Fluent-inspired**: Borrowing from Microsoft's Fluent Design but simplified for the web.

## Palette
- **Primary (Blue)**: `#005a9e` (Office Blue)
- **Word**: `#2b579a`
- **Sheet**: `#217346`
- **Slide**: `#d24726`
- **PDF**: `#b30b00`
- **Neutral**:
  - Background: `#faf9f8`
  - Ribbon: `#f3f2f1`
  - Border: `#edebe9`
  - Text: `#323130`

## Typography
- **Primary**: 'Segoe UI', system-ui, -apple-system, sans-serif.
- **Sizes**:
  - Ribbon Labels: 12px
  - Tab Headers: 14px
  - Document Text: 11pt (default)

## Components
- **Ribbon**: Tabbed interface with logical groupings.
- **Command Bar**: Quick access tools above the ribbon.
- **Canvas**: The main document area with a shadow and centered layout.
- **Status Bar**: Bottom-docked info bar.
